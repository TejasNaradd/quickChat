# 🚀 QuickChat – Real-Time Chat Application

QuickChat is a **real-time chat app** built with the **MERN stack**. It uses **Socket.IO** for instant messaging, **JWT authentication** for secure login, and **Cloudinary** for image sharing.

---

## ✨ Features

* 🔒 Secure **JWT-based authentication**
* 💬 **Real-time messaging** with Socket.IO
* 👥 **Online/Offline user status**
* 📷 **Image uploads** with Cloudinary
* 📡 **Seen & unseen message tracking**

---

## 🛠️ Tech Stack

* **Frontend:** React.js, Context API, TailwindCSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Authentication:** JSON Web Tokens (JWT)
* **Real-Time:** Socket.IO
* **Image Storage:** Cloudinary
